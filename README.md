# Rogue Engine
Maybe a placeholder name.

## General

#### What is this?
This is a role-playing game engine. Focusing on RPG-specific data first, allowing many data objects and systems to transfer to existing engines (like Unity or Unreal) if I get bored / take too long / abandon the project. This my friends is what the professionals call "self-awareness".

The plan is to create a core engine along with systems and data that are shared by most* RPGs, that will allow the game developer to create a "ruleset" defining what their game wants from the system. The game-specific code will allow swapping out, disabling, and extending upon the core systems and data.

#### Scope
This will not become an anything* engine. Those are projects with no focus, and no end in sight. When the project advances further on, I will release a full design document.
